# mpirmoradiyan.github.io

Personal website of Mohsen Pirmoradiyan, built with [Astro](https://astro.build) and deployed to GitHub Pages by `.github/workflows/deploy.yml`.

- `src/pages/`: home, journey, work, lab notes, CV
- `src/content/notes/`: lab notes, generated by `npm run sync` from the private notes archive (do not edit here)
- `src/data/`: profile text, journey stops, topics

```bash
npm install
npm run dev      # sync notes + local preview
npm run build    # sync notes + build to dist/
```
